SOBRE O PROJETOComo foi construído

Modelo de dados

Esquema estrela com 2 fatos (lançamentos e orçamento) e 3 dimensões (contas, unidades e calendário), ligados por 6 relações 1:N com filtro único.

Medidas DAX

Receita, Despesas, Resultado e Margem, cada uma com a versão orçada. A DRE tem 10 linhas, de Receita bruta a Lucro líquido, organizadas em pastas.

Visuais em HTML

Os cartões, a cascata, o orçado x realizado e a DRE são medidas DAX que geram HTML/CSS para o visual HTML Content. Não usam JavaScript nem recursos externos.

Regra de cores

Verde quando o resultado é bom e vermelho quando é ruim. Nas despesas a lógica se inverte. No orçado x realizado, o semáforo é ≤ 100%, ≤ 105% e acima disso.

NO POWER BI DESKTOPPrints do relatório

Os painéis desta página são a mesma saída HTML das medidas DAX do relatório, calculada para cada unidade. Arquivos do projeto e scripts estão no repositório.
